# 강사·학부모 매칭 관리

- `/admin` → **강사·학부모 매칭** → `/admin/matches`
- 기존 강사와 학부모 신청을 선택하고 학생 이름, 상태, 시작일·종료일, 관리 메모를 저장한다.
- 학생 이름과 날짜가 미확인이라면 비워둔다. 종료된 매칭도 목록에서 조회할 수 있다.
- 매칭 상태는 강사 회원의 활동 상태나 학부모 신청 처리 상태와 독립적이다.
- 관리자 세션만 조회·수정할 수 있다. 일반 클라이언트의 DB 직접 접근은 차단한다.
- 같은 강사·학부모·학생의 진행 중/일시 중지 매칭은 중복 생성하지 않는다.
- 두 관리 화면에서 동시에 수정하면 먼저 저장한 내용이 보호되며, 나중 요청은 새로고침을 안내한다.

## DB 적용

기존 DB에는 `docs/migrations/20260914_tutoring_matches.sql`을 한 번 적용한다.
새 프로젝트 전체 설치에는 `docs/supabase-schema.sql`을 사용한다.
실제 인물의 매칭 데이터는 공개 저장소에 포함하지 않는다.

## 검증

`node --test tests/matches.routes.cjs tests/lesson-reports.cjs`

실제 API 처리 코드를 실행하되 인증과 DB 경계는 격리한다. 관리자 권한, 요청 출처,
날짜·입력값 검증, 동시 수정 보호, 중복·참조 오류를 검사한다. 운영 DB의 제약 조건은
롤백하는 트랜잭션에서 별도 확인한다. 실제 관리 화면 조작은 관리자 로그인 후 확인한다.
